# Edu Map

Edu Map — это веб-сервис для **визуализации учебных планов** в виде интерактивного графа курсов.
Платформа позволяет студентам наглядно видеть структуру образовательной программы, понимать последовательность изучения дисциплин и планировать свою траекторию обучения.

## Технологии

Проект реализован с использованием современных веб-технологий:

- React
- TypeScript
- Vite
- ESLint
- Prettier
- Stylelint

## Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/visualizer-tech-project/frontend.git
cd frontend
```

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

## Предложить курс

Страница `/suggest-course` доступна после входа. Форма проверяет обязательные поля,
email и ссылку. Последнее предложение сохраняется в браузере, отправки на сервер нет.

## Локальный тестовый аккаунт

При запуске через `npm run dev` можно войти без сервера:

- Email: `test@edumap.local`
- Пароль: `Test123!`

После входа откроется `/suggest-course`. Форма сохраняет последнее предложение в браузере.
После перезагрузки страницы вход и данные формы сохранятся.
Тестовый аккаунт не обращается к API, поэтому разделы с серверными данными недоступны.
В production-сборке этот вход отключён.

## Сборка проекта

```bash
npm run build
```

## Проверка кода

Проверка JavaScript / TypeScript:

```bash
npm run lint
```

Проверка CSS:

```bash
npm run lint:css
```

Форматирование кода:

```bash
npm run format
```

## Структура веток

В проекте используется следующая модель ветвления:

```
main — стабильная версия проекта
dev — основная ветка разработки
```

## Для openapi

Вам необходимо вставить openapi.yml в корень проекта и в случае изменения openapi можно перегенерировать типы, используя команду ниже:

```
	npx openapi-ts
```
